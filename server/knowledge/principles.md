# Landlord Insight Principles

Crowdsourced patterns from Kamernet application outcomes.
**Team: add new insights here as patterns emerge from real data.**

## Positive signals

- Landlords mentioning "rustig" (quiet) strongly prefer working professionals over students — frame stability and quiet lifestyle.
- "Net aankomst" or "nette huurder" signals the landlord values presentation and reliability — lead with job contract and clean rental history.
- Income-to-rent ratio is a primary filter for most landlords: the Dutch norm is 3× monthly gross rent. Explicitly state income.
- Personalised applications that reference specific details from the listing (street, features, vibe) consistently outperform templates.
- Short-term contract workers improve outcomes by mentioning a permanent employer or guarantor.

## Neutral / contextual signals

- "Gezellig" language in the listing suggests a more casual landlord — a warm, personal tone in the application performs better than formal.
- Listings with many photos indicate an engaged landlord who takes pride in the property — mention specific features you liked.
- Student rooms listed without "no students" language are still competitive with working applicants if income is demonstrated (e.g., side job, parental guarantee).

## Negative signals / dealbreakers

- "Geen huisdieren" is an absolute dealbreaker — do not proceed if the user has pets.
- "Geen studenten" listings: flag to the user and suggest not applying unless they have strong mitigating factors.
- Generic openers ("Ik ben geïnteresseerd in uw woning...") consistently underperform. Flag if user drafts a template message.
- Applications that omit income information are frequently ghosted — always include it.
- Mentioning living alone in a property clearly listed for sharing has led to rejections.
